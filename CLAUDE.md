# CLAUDE.md

## Code comments

- Keep comments short. State the non-obvious "why" in as few words as possible; don't restate what a well-named function/variable/test already makes clear.
- Never reference a Jira ticket, PR, or other ticket-specific context in a comment. Write for someone reading the repo cold with no knowledge of the task that produced the change — describe the behavior/constraint itself, not the ticket that prompted it.
